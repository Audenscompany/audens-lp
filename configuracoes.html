Publicar alterações

Edite clientes e depoimentos nas abas ao lado. Aqui você envia tudo para o site e a landing atualiza sozinha em ~1 minuto.

1 · Conexão com o GitHub

Só precisa preencher uma vez. O token fica salvo só neste navegador, nunca sai daqui para outro lugar além do próprio GitHub.

Crie em github.com → Settings → Developer settings → Fine-grained tokens, com permissão Contents: Read and write apenas neste repositório. Ver o passo a passo
  1. Acesse github.com/settings/tokens?type=beta e clique em Generate new token.
  2. Em Repository access, escolha Only select repositories e selecione o repositório da LP.
  3. Em Permissions → Repository permissions, ache Contents e marque Read and write.
  4. Gere o token, copie (começa com github_pat_) e cole no campo acima.

2 · Enviar para o ar

Publica clientes-data.js e depoimentos-data.js com tudo que você editou nas abas ao lado.

Ver a landing ↗

Trocou de computador? Clique em Puxar versão publicada primeiro — assim você edita em cima do que já está no ar, e não do zero.
